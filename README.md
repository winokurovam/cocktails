# 🍸 Cocktails with the Local

Сайт для гостей бархоппинг-экскурсии по Алматы (RU / EN).

**Для гостей** (`index.html`):
- открывают сайт по QR-коду или ссылке, вводят имя;
- видят маршрут вечера и оценивают каждый бар (звёзды + отзыв);
- записывают выпитые коктейли с оценкой и впечатлениями;
- во вкладке «Мой вечер» видят итог, «коктейль вечера», могут **скачать открытку** или поделиться ей;
- получают **личную ссылку**, по которой их отзывы открываются в любое время, даже с другого телефона.

**Для гида** (`admin.html`):
- каталог баров;
- экскурсии: дата, код для гостей и свой маршрут на каждый вечер (бары в нужном порядке);
- QR-код и ссылка для каждой экскурсии;
- все отзывы, рейтинг баров, выгрузка в таблицу (CSV открывается в Excel / Google Таблицах).

## Как это работает сейчас

Пока база не подключена, сайт работает в **демо-режиме**: всё хранится только в браузере, где он открыт. Так можно всё потрогать, но отзывы гостей к вам не попадут. Для реальной экскурсии подключите бесплатную базу Supabase, это займёт около 15 минут.

## Шаг 1. Онлайн-база (Supabase, бесплатно)

1. Зарегистрируйтесь на <https://supabase.com> и нажмите **New project**. Регион лучше ближе к Алматы, например Frankfurt. Пароль базы придумайте и сохраните.
2. Откройте **SQL Editor → New query** и вставьте весь файл [`supabase/schema.sql`](supabase/schema.sql).
   **В последней строке** замените `your-email@example.com` на свой email. Нажмите **Run**.
3. **Authentication → Users → Add user → Create new user**: укажите тот же email и пароль и поставьте галочку *Auto Confirm User*. С ними вы будете входить в кабинет гида.
4. **Authentication → Sign In / Providers**: выключите *Allow new users to sign up*, чтобы никто, кроме вас, не мог зарегистрироваться.
5. **Project Settings → API**: скопируйте *Project URL* и ключ *anon public*.
6. Вставьте их в файл [`js/config.js`](js/config.js):
   ```js
   SUPABASE_URL: "https://xxxx.supabase.co",
   SUPABASE_ANON_KEY: "eyJhbGciOi...",
   ```
   Ключ `anon` публичный, его можно хранить в коде: доступ защищён правилами в базе. Гости могут только сохранять и читать **свои** отзывы, а всё остальное видите только вы.

## Шаг 2. Публикация сайта (GitHub Pages, бесплатно)

1. В репозитории на GitHub: **Settings → Pages**.
2. *Source*: **Deploy from a branch**, ветка `main`, папка `/ (root)`, затем **Save**.
3. Через минуту сайт будет доступен:
   - для гостей: <https://winokurovam.github.io/cocktails/>
   - кабинет гида: <https://winokurovam.github.io/cocktails/admin.html>

## Как проводить экскурсию

1. Кабинет гида → **Бары**: добавьте бары один раз (название, адрес, по желанию ссылка на 2ГИС).
2. **Экскурсии → Новая экскурсия**: дата, код (создаётся сам, например `NOV04`), маршрут.
3. Нажмите **QR и ссылка**: покажите QR гостям или отправьте ссылку в чат группы.
4. **Секретный маршрут:** гости видят только первый бар, остальные отображаются как «🤫 Секретная остановка».
   Когда группа приходит в следующий бар, нажмите в карточке экскурсии **«Открыть следующий ▶»**. У гостей бар появится сам в течение ~20 секунд.
   Если открыли случайно, нажмите **«↩ Спрятать»**. Скрытые бары не передаются гостям вообще, поэтому подсмотреть их не получится.
5. **Фотоальбом:** во вкладке «📸 Альбом» гости и вы загружаете фото вечера, и все участники экскурсии видят общую ленту.
   Загружать фото можно в день экскурсии и ещё 3 дня после. В кабинете гида во вкладке «Фото» можно добавить свои фото и удалить лишние.
6. **Рейтинг:** на каждом открытом баре гости видят среднюю оценку всех ваших гостей.
7. После вечера откройте **Отзывы**: там всё, что написали гости, и выгрузка в таблицу.

> Если база создавалась раньше, один раз выполните по порядку в Supabase → SQL Editor:
> [`supabase/002_secret_route.sql`](supabase/002_secret_route.sql), затем [`supabase/003_album_and_rating.sql`](supabase/003_album_and_rating.sql).
